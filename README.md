Building upon networking and parallel computing fundamentals, this course explores the technologies and techniques used to develop distributed systems and scalable software architectures.

## Using This Repository

These examples are provided to:

- demonstrate programming techniques introduced in lecture;
- serve as reference implementations;
- help prepare for laboratories and assignments;
- encourage experimentation and exploration.

Students are encouraged to:

- modify the examples;
- experiment with different implementations;
- extend the provided code.


## Academic Integrity

These materials are provided for educational purposes only.

Unless explicitly stated otherwise:

- Do **not** submit these examples as your own work.
- Use them to understand concepts and programming techniques.
- All submitted assignments must represent your own original work and comply with the course's academic integrity policy.

## Prerequisites

Students are expected to have programming experience and a solid understanding of:

- object-oriented programming,
- data structures,
- algorithms, and
- basic networking concepts
